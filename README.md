# 요한계시록 암송 퀴즈 (개역한글)

대표님 개인 암송용입니다. 설치·인터넷 없이 `index.html` 파일 하나로 동작합니다.

## 여는 법
- PC: `index.html`을 두 번 눌러 브라우저(크롬·엣지)로 엽니다.
- 휴대폰: 이 파일을 카카오톡 "나에게 보내기"나 구글 드라이브로 보내고, 휴대폰에서 받은 파일을 크롬(또는 삼성 인터넷)으로 엽니다. 처음 연 뒤 "홈 화면에 추가"를 해 두면 다음부터 바로 열립니다.
- 기록(장별 정답률·틀린 절·복습 날짜·글자 크기)은 그 기기의 브라우저에만 저장됩니다. PC와 휴대폰 기록은 따로입니다. 브라우저 방문 기록을 지우면 기록도 지워질 수 있습니다.

## 사용법 3줄
1. 장 버튼을 눌러 범위를 고릅니다(여러 장 가능, "1~5"·"1,3,5"처럼 입력해도 되고 "전체"도 있음). 장 버튼 색이 그 장의 정답률입니다.
2. 공부 방식을 고르고 "시작하기": 단계 학습(추천) / 빈칸(20·50·80%) / 전체 쓰기 / 장절 맞히기. 빈칸·전체 쓰기·장절 맞히기는 순서대로·무작위를 고를 수 있습니다.
3. 채점 화면에서 틀린 낱말(✕)과 정답을 비교하고, 끝나면 "틀린 절만 다시". 다음 날부터는 첫 화면의 "오늘 복습할 절 ○개"를 누릅니다.

## 공부 방식 (충주 안)
- 단계 학습: 고른 장을 3~5절씩 묶어 ① 읽기 → ② 빈칸 20% → ③ 빈칸 50% → ④ 첫 글자만 보고 쓰기 → ⑤ 전체 쓰기. 묶음의 낱말을 95% 이상 맞히면 다음 단계, 아니면 같은 단계를 다시 합니다. 한 장을 마치면 그 장 구절 6개로 장절 맞히기를 합니다.
- 빈칸은 뜻 있는 낱말(긴 낱말)부터 가리고, 조사는 남깁니다. 20%에서 가린 낱말은 50%에서도 가려집니다.
- 틀린 절은 그 회차 끝에 한 번 더 내고, 그다음 1일 → 3일 → 7일 → 14일 뒤 복습 목록에 나옵니다. 틀리면 1일로 돌아갑니다.
- 채점: 띄어쓰기·문장부호·따옴표는 보지 않습니다. 낱말·조사·어미는 개역한글 그대로여야 정답입니다("가라사대"를 "말씀하시되"로 쓰면 오답).

## 입력 (연주 안)
- 휴대폰은 ②~④단계를 낱말 카드로 풀고(누르는 순서대로 채워짐, 빈칸을 다시 누르면 그 칸부터 다시), ⑤ 전체 쓰기만 직접 씁니다. 휴대폰 키보드의 마이크(말로 입력)를 써도 됩니다.
- PC는 처음부터 직접 씁니다. 빈칸에서 Enter를 누르면 다음 칸으로 갑니다.
- 첫 화면 "입력"에서 자동 / 낱말 카드 / 직접 쓰기를 바꿀 수 있습니다. 글자 크기 3단계(가 버튼)와 밤 모드(🌙)는 다음에 열어도 그대로입니다.

## 본문 출처와 검증
- 본문: 대한성서공회 성경전서 개역한글판(1961), 대한성서공회 온라인 성경 "개역한글" 요한계시록 1~22장 화면 문구(https://www.bskorea.or.kr/bible/korbibReadpage.php?version=HAN&book=rev&chap=1 … chap=22, 2026-10-27 받음). 소제목·각주(사본 차이 설명)는 빼고 절 본문만 넣었습니다. 원본 데이터: `data/요한계시록_개역한글.json`.
- 절 수: 1장 20, 2장 29, 3장 22, 4장 11, 5장 14, 6장 17, 7장 17, 8장 13, 9장 21, 10장 11, 11장 19, 12장 17, 13장 18, 14장 20, 15장 8, 16장 21, 17장 18, 18장 24, 19장 21, 20장 15, 21장 27, 22장 21 = 404절 (만들 때마다 자동 확인).
- 대조: 처음 받은 getBible 공개 본문("Korean")과 404절 전부를 글자 단위로 대조했더니 158절이 달랐습니다(띄어쓰기만 108절, 글자 50절). 글자가 다른 곳은 getBible 쪽이 "볼찌어다→볼지어다", "세째→셋째"처럼 현대 표기로 바꾸었거나 "빌라델비아→빌라멜비아", "좌우→죄우", 낱말 빠짐 같은 오류였습니다. 그래서 본문은 모두 대한성서공회 문구를 썼습니다.
